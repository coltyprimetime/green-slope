# Green slope

One page. Set the device flat on the green, front pointed at the hole, pinch (glasses) or tap (phone). It speaks the slope percent, uphill/downhill toward the hole, and which way it breaks — at that spot only.

Built for the Meta Ray-Ban Display web-app runtime (600×600, additive display, Neural Band = Enter/arrows) and works in a phone browser as the fallback. No accounts, no data leaves the device.
